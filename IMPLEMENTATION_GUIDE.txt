WATCHER — DIRECT IMPLEMENTATION

1) পুরোনো project folder backup নিন।
2) এই ZIP extract করুন।
3) Android Studio / VS Code-এ extracted "watcher" folder খুলুন।
4) Terminal-এ চালান:

   flutter clean
   flutter pub get
   flutter run

5) Release APK:

   flutter build apk --release

APK path:
   build/app/outputs/flutter-apk/app-release.apk

OMDb:
- আপনার দেওয়া API key default হিসেবে code-এ আছে। তাই সরাসরি run করবে।
- অন্য key ব্যবহার করতে চাইলে:

  flutter run --dart-define=OMDB_API_KEY=YOUR_KEY

IMPORTANT:
- পুরোনো app-এর একই package id (com.example.watcher) রাখা হয়েছে।
- আগের SharedPreferences data থাকলে নতুন model-এ migrate করার logic আছে।
- Search result tap করলে OMDb full details এবং Series Season 1 episode count আনার চেষ্টা করবে।
- Plus button manual add form খুলবে।
- Detail page থেকে status, season, episode, edit ও delete করা যাবে।
- Settings থেকে TXT backup export এবং TXT/JSON import করা যাবে।
